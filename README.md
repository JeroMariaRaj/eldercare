# Elder Day Care & Senior Activity Center - Premium HTML Template

A modern, responsive, SEO-friendly HTML5 template designed for Elder Day Care Centers, Senior Activity Communities, and Senior Wellness facilities.

## Features

- **Pure HTML5 / Tailwind CSS / Vanilla JS** (No complex frameworks, No PHP)
- **19 Complete HTML Pages** including variations for Home pages, Services, Blog, and Contact.
- **Family Dashboard**: A comprehensive, non-admin dashboard for families to monitor senior care, wellness, activities, and meals.
- **Dark/Light Mode** with local storage support.
- **Responsive & Mobile Ready**.
- **SEO Optimized** with semantic HTML tags.
- **Clean & Reusable Code**.

## Page Structure

1. `index.html` - Home Page 1 (General Senior Care)
2. `index-2.html` - Home Page 2 (Senior Activity Center)
3. `about.html` - About Us
4. `programs.html` - Programs List
5. `program-details.html` - Specific Program View
6. `facilities.html` - Facilities Showcase
7. `caregivers.html` - Caregiver Team
8. `blog.html` - Blog Listing (with search and category filtering in JS)
9. `blog-details-1.html` to `blog-details-4.html` - 4 Complete Blog Details mapped to each other
10. `contact.html` - Contact Form & Map
11. `pricing.html` - Pricing Plans
12. `login.html` & `register.html` - Family Auth Pages
13. `family-dashboard.html` - Dedicated Dashboard for Family Members
14. `404.html` - Error Page
15. `coming-soon.html` - Coming Soon Page with Countdown

## Instructions

1. Simply open any `.html` file in your browser to view the template.
2. Custom styling is located in `assets/css/style.css`.
3. Custom JavaScript for interactions, theme toggling, and dashboard features are located in `assets/js/main.js` and `assets/js/blog.js`.

*Note: As requested, the admin dashboard has been strictly omitted. The dashboard provided is purely for families to track their seniors' well-being.*
